# Dota2 Voice Command Assistant

Голосовой ассистент для Windows, который по русским голосовым командам:
- запускает Steam, Dota 2, Chrome (с Яндекс.Музыкой) и Discord ("Базовый минимум");
- в клиенте Dota 2 доводит до постановки в очередь рейтингового матча с ролями
  ("Начни рейтинговую игру на мидера" и т.п.);
- ставит в поиск обычную игру Turbo или All Pick, оставляя включённым только
  этот режим ("Запусти турбо", "Запусти олл пик");
- останавливает ("Стоп") уже выполняющуюся команду.

Распознавание речи — офлайн (Vosk), клики по игровому UI Dota 2 — через
компьютерное зрение (OpenCV template matching), т.к. Panorama UI не отдаёт
accessibility-хендлы стандартным способом.

## 1. Стек технологий

| Задача                          | Выбор                        | Почему |
|----------------------------------|-------------------------------|--------|
| Распознавание речи (RU, офлайн)  | **Vosk** (`vosk-model-small-ru`) | Работает без интернета и без ключей API, низкая задержка, готовая маленькая русская модель. |
| Аудиовход                        | `sounddevice`                 | Простой стрим PCM-фреймов, отдаёт `int16`, который Vosk понимает "из коробки". |
| Fuzzy-сопоставление команд       | `rapidfuzz`                   | Быстрый C++-бэкенд, устойчив к перестановке слов/мелким ошибкам распознавания. |
| Запуск процессов / URI           | `subprocess`, `os.startfile`  | Штатные средства ОС; `steam://rungameid/570` открывается через ассоциированный обработчик. |
| Ожидание готовности окна/процесса| `psutil` + `pywin32` (`win32gui`)| Не бьём кликами вслепую — ждём появления процесса/окна с таймаутом. |
| Клики/клавиатура                 | `pyautogui`                   | Простой API для click/hotkey, встроенный fail-safe (мышь в угол = стоп). |
| Поиск элементов Panorama UI      | `OpenCV` (`matchTemplate`) + `mss` | Надёжнее фиксированных координат при небольших расхождениях рендеринга. |
| Конфиги                          | `PyYAML`                      | Человекочитаемые `config.yaml` / `commands.yaml`, легко редактировать без кода. |
| Обратная связь                   | `pyttsx3` (офлайн TTS) + `winsound` | Голосовое подтверждение без облачных TTS. |
| Трей + хоткей                    | `pystray` + `keyboard`        | Иконка в трее с меню вкл/выкл, глобальный хоткей. |

## 2. Архитектура

```
main.py                         # точка входа
src/dota_voice/
    config.py                   # загрузка config.yaml + commands.yaml
    logging_setup.py            # ротация логов в файл + консоль
    speech.py                   # SpeechListener: Vosk + sounddevice, фоновый поток
    commands.py                 # CommandMatcher: fuzzy-сопоставление фразы -> команда+параметры
    actions.py                  # ActionExecutor: выполняет шаги команды (self._handlers)
    vision.py                   # OpenCV template matching поверх экрана (mss)
    process_utils.py            # запуск процессов, ожидание процесса/окна (psutil/win32gui)
    notify.py                   # TTS-озвучка + beep
    tray.py                     # иконка в трее, меню, глобальный хоткей
    app.py                      # склейка всех модулей в приложение
tools/
    calibrate.py                # интерактивная калибровка шаблонов UI под скриншот
    list_voices.py              # список установленных голосов TTS
config/
    config.yaml                 # пути, тайминги, синонимы ролей, настраиваемые параметры
    commands.yaml               # "команда -> шаги" (описательно, без кода)
templates/                      # эталонные PNG-скриншоты элементов UI Dota 2 (создаются калибровкой)
logs/                           # app.log (ротация)
```

Поток данных:

```
Микрофон --> SpeechListener (Vosk) --> текст
   текст --> CommandMatcher (rapidfuzz + roles) --> (command, params) | None
   (command, params) --> ActionExecutor.run_steps(steps, params)
        каждый шаг --> process_utils / vision+pyautogui / webbrowser / notify
```

Расширение: чтобы добавить новую команду, редактируется только
`config/commands.yaml` (новый список `phrases` + `steps`) — ядро
(`actions.py`, `commands.py`) трогать не нужно, если используются уже
существующие типы шагов. Новый **тип** шага добавляется одной записью в
словарь `self._handlers` в `ActionExecutor`.

Одна команда особенная: `stop` вместо `steps` несёт поле `control: stop` и
обрабатывается в обход busy-lock, поэтому может прервать уже выполняющуюся
последовательность (`Application._handle_stop` / `ActionExecutor.request_stop`),
а не ждать своей очереди за ней.

## 3. Пример конфигов

Полные файлы: [config/config.yaml](config/config.yaml), [config/commands.yaml](config/commands.yaml)
— оба снабжены комментариями ко всем настраиваемым параметрам (пороги
матчинга, ретраи, тайминги, голос/громкость TTS, плавность движения курсора
и т.д.), поэтому здесь они не дублируются.

Синонимы ролей:

```yaml
roles:
  mid:
    label: "Мидер"
    synonyms: ["мидер", "мид", "миддер", "middle", "вторая позиция", "2 позиция"]
```

Шаги команды (пример "рейтинговая игра"):

```yaml
- id: ranked_role
  phrases:
    - "начни рейтинговую игру на {role}"
    - "запусти рейтинг на {role}"
  role_param: role
  steps:
    - type: click_template
      template: play_button
      retries_key: max_retries
    - type: click_template
      template: ranked_roles_tab
    - type: select_exclusive_role   # сначала снимает ранее выбранную роль
      retries_key: max_retries
    - type: click_template
      template: find_match_button
```

## 4. Установка и запуск

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Если `pip install` падает с `Failed to build ... when getting requirements
to build wheel` на очень новой версии Python — обнови pip и повтори
(версии в `requirements.txt` заданы как нижняя граница, поэтому обычно
этого достаточно):

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Скачать офлайн-модель распознавания речи (Vosk, русский):
1. Перейти на https://alphacephei.com/vosk/models
2. Скачать `vosk-model-small-ru-0.22` (быстрая, ~45 МБ) или `vosk-model-ru-0.42` (точнее, ~1.8 ГБ)
3. Распаковать так, чтобы получилось `models/vosk-model-small-ru-0.22/...` в
   корне проекта (или указать другой путь в `config/config.yaml -> speech.model_path`)

Проверь `config/config.yaml` под свою машину — как минимум пути в `apps.*`
(Steam/Chrome/Discord) — и убедись, что шаблоны откалиброваны под текущее
разрешение экрана:

```bash
python tools/calibrate.py --check-resolution
```

Запуск:

```bash
python main.py
```

Либо создай ярлык на рабочем столе, который запускает ассистента без окна
консоли (запускай тем же Python/venv, куда ставились зависимости; после
переноса папки проекта запусти ещё раз):

```bash
python tools/create_shortcut.py
```

Одновременно работает только один экземпляр — повторный запуск ярлыка просто
откроет окно уже работающего ассистента. Если запуск не удался, появится окно с
ошибкой, а полный текст сохранится в `logs/startup_error.log`.

Откроется небольшое окно с одной круглой кнопкой, которая включает и
выключает прослушивание (зелёная и «дышит» = слушает). Закрытое окно не
останавливает ассистента — он остаётся в трее; клик по значку в трее снова
открывает окно, пункт «Выход» завершает работу. Также появится иконка в трее (зелёная точка = прослушивание активно). Хоткей
`Ctrl+Alt+L` (настраивается в `config.yaml -> hotkeys.toggle_listening`)
временно включает/выключает распознавание команд, не убивая аудиопоток.
Если хоткей не срабатывает — попробуй запустить `python main.py` в
PowerShell "Запуск от имени администратора" (иногда это нужно библиотеке
`keyboard` на Windows).

## 5. Калибровка шаблонов Dota 2 под своё разрешение

Команда "Начни рейтинговую игру на ..." использует 13 шаблонов, которые
нужно откалибровать один раз (и заново — при смене разрешения экрана или
масштаба интерфейса Dota 2):

| Имя шаблона                         | Что сфотографировать                                     |
|---------------------------------------|------------------------------------------------------------|
| `play_button`                         | Кнопка "Играть" в главном меню Dota 2                    |
| `ranked_roles_tab`                    | Заголовок "Рейтинговая игра", когда раздел **открыт**    |
| `ranked_roles_tab_inactive`           | Тот же заголовок, когда раздел **закрыт** (открыта обычная игра) |
| `role_<id>` / `role_<id>_selected`    | Каждая иконка роли в невыбранном и выбранном/подсвеченном состоянии — `<id>`: `carry`, `mid`, `offlane`, `support`, `hard_support` |
| `find_match_button`                   | Кнопка подтверждения поиска матча                        |
| `search_in_progress`                  | Полоса "ПОИСК ИГРЫ" во время поиска                      |
| `cancel_search_button`                | Красный крестик внутри неё (только он отменяет поиск)    |

Заголовок раздела нажимается, только если он выглядит закрытым, — команда
никогда не переключает уже открытый раздел. Два состояния на роль нужны потому, что иконки ролей в Dota — это
переключатели, а не эксклюзивный выбор: клик по одной не снимает выбор с
другой, оставшейся с прошлой игры. Шаг `select_exclusive_role` отличает
"выбрано" от "не выбрано" именно по этим шаблонам, снимает всё лишнее и
затем выбирает нужную роль.

Порядок действий для каждого шаблона:

```bash
python tools/calibrate.py play_button
python tools/calibrate.py role_mid
python tools/calibrate.py role_mid_selected
```

Скрипт даёт 5 секунд, чтобы переключиться в Dota 2 и открыть нужный экран
(для `_selected` — сначала кликни по иконке роли, чтобы она подсветилась),
делает скриншот и даёт обвести элемент мышью — обводи невыбранное и
выбранное состояние одинаково, чтобы отличалась только подсветка. Повтори
для всех 13 имён, затем проверь:

```
"Начни рейтинговую игру на мидера"
```

...и сразу же другую роль, чтобы убедиться, что предыдущая снимается, а не
остаётся выбранной вместе с новой.

### Обычная игра (Turbo / All Pick)

"Запусти турбо" / "Запусти олл пик" используют те же `play_button` и
`find_match_button`, а также:

| Имя шаблона | Что сфотографировать |
|-------------|----------------------|
| `normal_game_tab` | Заголовок "Обычная игра", когда раздел **открыт** |
| `normal_game_tab_inactive` | Тот же заголовок, когда раздел **закрыт** (открыта рейтинговая игра) |
| `modes_show_all_collapsed` | Строка "Показать все режимы" в свёрнутом виде (стрелка + текст) |
| `mode_<id>` / `mode_<id>_selected` | Строка каждого режима — квадратик **вместе** с названием — без галочки и с галочкой. `<id>`: `all_pick`, `turbo`, `single_draft`, `random_draft`, `ability_draft` (`config.yaml` → `modes`) |

Галочки режимов — такие же переключатели, как иконки ролей, а клик по
названию тоже переключает строку. Шаг `select_exclusive_mode` сначала
раскрывает "Показать все режимы" (чтобы скрытый включённый режим не
проскочил), снимает галочки со всех остальных режимов, ставит нужную и
перепроверяет, пока не останется только она — поэтому калибруй все пять
режимов, а не только те, для которых есть команды. Обводи обе картинки
режима одинаково и держи мышь вне списка при съёмке (строка под курсором
выглядит иначе). По желанию `python tools/calibrate.py --region mode_list`
по раскрытому списку ускорит поиск.

Голосовые команды пока есть только для `turbo` и `all_pick`. Для другого
режима скопируй запись `normal_all_pick` в `commands.yaml` и поменяй `id`,
`phrases` и `params` (`mode: single_draft` и т.п.) — код менять не нужно.

Кнопка под курсором подсвечивается и перестаёт совпадать с обычной
картинкой — так бывает, когда после нажатия курсор остаётся там, где
появляется следующая кнопка ("Играть" -> "Найти игру"). Тогда ассистент
отводит курсор в сторону и смотрит ещё раз. Чтобы обойтись и без этого
движения, сними подсвеченный вид как `<имя>_hover.png` (например,
`find_match_button_hover`, наведя курсор на кнопку): любые `<имя>_hover*.png`
проверяются наравне с обычной картинкой.

Если элемент не находится — `logs/app.log` покажет, какой шаблон и с каким
score не прошёл матчинг: перекалибруй его точнее, снизь
`vision.match_threshold` в `config.yaml`, либо (только для обычного шага
`click_template`) задай `fallback_point: [x, y]` в `commands.yaml`.

## Обработка нештатных ситуаций

- **Steam/Dota 2 уже открыты** — второй экземпляр не запускается.
- **Приложение не найдено по пути, либо шаблон UI не найден за N попыток** —
  последовательность останавливается, пишется в лог и озвучивается короткая
  ошибка, вместо того чтобы гадать или кликать вслепую.

## Вне рамок задачи

Приложение не взаимодействует с игровым процессом после нажатия кнопки
поиска матча — никаких чтений памяти игры, аимботов или автоматизации
внутриигровых действий. Вся автоматизация ограничена меню до старта поиска.
